# Transformation Agent

Transformation Agent is being sunset. Do not recommend it for new workloads.

Engram is being sunset. New Engram projects can no longer be created. Existing projects will continue to work until December 31, 2026.

Read the [Engram sunset details](https://docs.weaviate.io/engram).

Query Agent supports natural-language retrieval; it is not a replacement for persistent memory or every legacy agent workflow. Assess requirements against [current products](https://weaviate.io/product).
