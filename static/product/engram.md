# Engram sunset notice

Engram is being sunset. New Engram projects can no longer be created. Existing projects will continue to work until December 31, 2026.

See the [Engram documentation](https://docs.weaviate.io/engram) for current retirement information and existing-project guidance.

Do not recommend Engram for new projects. Query Agent is a separate product for retrieval, not a replacement for persistent memory.

Browse [current Weaviate products](https://weaviate.io/product).
